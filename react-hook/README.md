## 과제명
useState & useEffect 활용 앱

## 🚀 주요 기능

- **추가**: 입력창에 할 일을 적고 추가 버튼을 눌러 목록에 추가합니다. (공백 입력 시 알림창 표시)
- **완료**: 체크박스를 클릭하여 완료 상태를 토글할 수 있으며, 완료 시 취소선이 표시됩니다.
- **삭제**: 삭제 버튼을 통해 목록에서 항목을 제거합니다.
- **빈 목록 처리**: 할 일이 없을 경우 "할 일 목록이 없습니다"라는 메시지를 보여줍니다.


## 🤔 느낀 점 / 어려웠던 점

### 느낀점
혼자 투두 리스트를 만들다가 막히는 부분이 많아 투두리스트 만드는 강의를 참고했는데 
조금 어려워서 한 강의를 3번 정도 돌려보며 구조를 이해했습니다.
특히 부모 컴포넌트(App)에서 자식 컴포넌트들로 Props를 넘겨주고, 다시 자식에서 부모의 상태를 바꾸는 개념을 
코드로 짜보면서 어떻게 데이터를 주고받는지 감을 잡을 수 있었습니다. 

### 어려웠던점
1. [...todos]처럼 매번 복사해서 상태를 업데이트하는 '불변성 유지' 개념이 좀 어려웠습니다
또 map을 돌릴 때 왜 고유한 값(Math.random())을 꼭 쥐여줘야 하는지 이해하는데 좀 걸렸습니당

2. 이어서 필수 조건인 useEffect와 localStorage를 함께 사용해서 
데이터를 저장하는 개념은 알겠는데 막상 제 코드에 적용하려니 
어떻게 코드를 작성해야 할지 전혀 감이 잡히지 않았습니다.
