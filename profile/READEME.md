# 과제명: 나만의 프로필 페이지

## 작업 내용
- **프로필 이미지**: `img` 태그를 활용한 사진 삽입 및 CSS 크기 조절
- **자기소개**: 이름, 전공, 한 줄 소개 포함
- **관심사 및 기술목록**: `ul`, `li` 태그를 활용한 관심사 및 기술 목록 작성
- **시맨틱 구조**: `header`, `main`, `footer` 태그를 사용함
- **디자인 커스텀**:
  - Flexbox를 활용한 요소 정렬
  - Box Model 적용 (Border, Padding, Margin)
  - 글자 크기, 글꼴 및 색상 커스텀
